GHN Madrasa Manager — Android Installable Web App (PWA)

গুরুত্বপূর্ণ: শুধু ZIP extract করে index.html চালালে Chrome-এ চলবে, কিন্তু Android-এ পূর্ণ App install (PWA) করতে HTTPS ওয়েব-ঠিকানায় প্রকাশ করতে হবে। এই ZIP-এ প্রয়োজনীয় PWA ফাইল আছে। GitHub Pages বা অন্য HTTPS hosting-এ পুরো ফোল্ডারের সব ফাইল আপলোড করতে হবে। এরপর Android Chrome-এ সেই https:// ঠিকানা খুলে ⋮ মেনু > Install app / Add to Home screen চাপুন।

ব্যাকআপ: অ্যাপের রিপোর্ট ট্যাব > ডেটা ব্যাকআপ > ব্যাকআপ ডাউনলোড। JSON ফাইলে শিক্ষার্থী, শিক্ষক, বেতন, জমার হিসাব এবং ছবি থাকবে। ফোন বদলালে বা ডেটা ফেরত আনতে রিপোর্ট > ব্যাকআপ ফেরত বেছে JSON ফাইল নির্বাচন করুন। ব্যাকআপ ফাইল নিরাপদ জায়গায় রাখুন।

SMS: বার্তা তৈরি হয় ফোনের Messages অ্যাপে; Send নিজে চাপতে হবে।

ডেটা: ডেটা এই ডিভাইসের ব্রাউজার স্টোরেজে থাকে। একই ইনস্টল করা PWA-তে ব্যবহার করা যাবে; আলাদা ফোনে নিজে থেকে sync হয় না।
